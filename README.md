# File XOR Modifier

## О проекте

Это тестовое задание реализует десктопное приложение на Qt для пакетной обработки файлов с помощью XOR-шифрования.

Приложение ориентировано на простоту использования и безопасную обработку файлов в фоне, с возможностью управления через пользовательский интерфейс.

## Основные возможности

- маска входных файлов, например .txt, testFile.bin
- настройка необходимости удалять входные файлы или нет
- путь для сохранения результирующих файлов
- путь для поиска файлов для обработки
- действия при повторении имени выходного файла: перезапись или
модификация, например, счетчик к имени файла
- работа по таймеру или разовый запуск
- периодичность опроса наличия входного файла (таймер)
- значение 8 байт для бинарной операции модификации файла в формате hex например 1234567890ABCDEF

## Реализованные технические детали

- Архитектура разделена на пользовательский интерфейс и рабочий поток:
  - `MainWindow` отвечает за UI, ввод параметров и состояние кнопок.
  - `FileProcessor` выполняет файл-ориентированную обработку в отдельном потоке.
- Использован `QThread` и `QObject::moveToThread` для безопасной асинхронной работы.
- Реализована прерываемая обработка с поддержкой pause/resume через `QMutex` и `QWaitCondition`.
- Сетевой буфер 64 КБ используется для эффективного чтения и записи больших файлов.
- Управление именами файлов при коллизии реализовано через генерацию уникального имени.
- Проверка формата XOR-ключа осуществляется с помощью регулярного выражения и валидатора.

## Структура репозитория

- `main.cpp` — точка входа приложения.
- `mainwindow.h/.cpp` — интерфейс и логика взаимодействия с пользователем.
- `fileprocessor.h/.cpp` — исполнительный модуль обработки файлов.
- `CMakeLists.txt` — конфигурация сборки проекта.
- `Main.qml` — вспомогательный файл, не используемый в текущей реализации.

## Как запустить

1. Откройте проект в Qt Creator или соберите через CMake с установленными Qt6 Widgets.
2. Запустите `FileXORModifier`.
3. Укажите папку с исходными файлами, шаблон маски, выходную папку и XOR-ключ.
4. Нажмите `Старт`.
